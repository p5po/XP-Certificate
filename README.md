# 🪟 Sabr-XP (Windows XP Certificate Wizard)

An interactive, nostalgic frontend prank application styled after the classic **Windows XP (Luna Theme)**. 

Users are guided through a retro OS setup wizard with tailored humorous questionnaires assessing their "patience and procrastination" levels across various tracks, ultimately exporting an official, signed achievement certificate in high-resolution PDF format.

---

## ✨ Features

- **Pixel-Perfect Windows XP UI**: Classic blue title bars, bevels, 3D buttons, and authentic OS system error sounds.
- **Dynamic Track-Based Questionnaires**: Unique questions and grading logic tailored to each selected specialty.
- **Interactive Easter Eggs**:
  - System warning triggers on attempt to maximize or close the wizard.
  - Taskbar interceptors producing critical OS stop alerts.
  - Start Menu prank redirecting shortcut-seekers back to the evaluation.
- **Client-Side Canvas Engine**: Real-time programmatic certificate generation rendering dynamic text, grading badges, timestamps, and custom signatures.
- **Direct PDF Export**: High-fidelity landscape A4 PDF export powered by `jsPDF`.
- **Fully Responsive**: Mobile-friendly layout designed for seamless touch interaction and mobile viewports.

---

## 🛠️ Built With

- **HTML5 & CSS3** (Custom retro UI styles and flex layouts)
- **Vanilla JavaScript** (State management, event routing, and Web Audio API)
- **HTML5 Canvas API** (Dynamic vector rendering and certificate composing)
- **jsPDF** (Client-side vector-to-PDF export)
